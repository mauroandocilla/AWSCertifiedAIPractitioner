# Guía de categorías — Quiz v2 (209 preguntas)

Las 209 preguntas del banco de Quiz v2 (TutorialsDojo) agrupadas por el concepto real que evalúan, en vez de 209 ítems sueltos para memorizar. Cada categoría tiene su propio archivo con el resumen del concepto, el "truco" para reconocer variantes repetidas de la misma pregunta, y la lista completa de preguntas con su respuesta correcta. Esta misma guía también vive dentro de la app en `/quiz-v2/categorias`.
